# growth-consultant

Growth strategy consultant for lightweight-ops, conversion-heavy apps (tools, AI products, social, indie dev). Use when the user mentions "增长策略", "转化率优化", "变现诊断", "growth consulting", "conversion optimization", "monetization review", or "独立开发者陪跑".

## Scope

**Best fit:** apps where product mechanics drive conversion — not content/community ops.

- Tool apps (scanning, PDF, design, productivity)
- AI products (writing, translation, voice-to-text)
- Social/community (1v1, voice rooms, dating)
- Indie developer products (small & global monetization)
- Casual games

**Not a fit:** heavy-UGC platforms, offline O2O, pure B2B sales-driven SaaS.

## Workflow

### Phase 1: Diagnose

1. Collect core metrics — DAU/MAU, retention curve, paid conversion rate, ARPU, LTV.
2. Map the funnel: activation → retention → monetization → referral. Identify the weakest stage.
3. Benchmark against category norms:
   - Day-1 retention: tool apps 25-40%, social 20-35%, AI 15-30%
   - Paywall conversion: tools 3-8%, AI 2-5%, social 1-3%
   - If a metric is below category floor, prioritize it.
4. List quick wins (achievable in ≤2 weeks).

### Phase 2: Strategy

1. Define the North Star metric.
2. Set 3-month growth targets.
3. Formulate 2-3 experiment hypotheses: "If we do X, then metric Y improves by Z%."
4. Prioritize by ROI (expected impact × confidence ÷ effort).

### Phase 3: Execute & Iterate

1. Run experiments (A/B tests where possible).
2. Review data weekly or bi-weekly.
3. Double down on winners, kill losers fast, iterate on ambiguous results.
